# 0010. Brand: rhizome mark, monoline wordmark, product palette

- Status: Accepted
- Date: 2026-10-18
- Decision log: D14

## Context and Problem Statement

The project needs a recognisable identity that fits the name (see [ADR 0007](0007-name-rhizo.md)).

What should the mark, the wordmark and the brand colors be?

## Considered Options

- Rhizome mark, monoline wordmark, product theme palette as brand colors

## Decision Outcome

Chosen option: A rhizome mark (seed, shoots, one cross-link), a monoline wordmark and the product theme palette as brand colors, because the log records the choice. `assets/brand/BRAND.md` explains that the branch colors come from `crates/core/src/theme.rs`, so rhizo's own mindmaps are on-brand by default.

### Consequences

- Good: The mark is itself a rhizo document.
- Good: Brand and product share one palette.
- Bad: The dotted cross-link must stay in the mark, and the wordmark is never set in a font (see `assets/brand/BRAND.md`).
