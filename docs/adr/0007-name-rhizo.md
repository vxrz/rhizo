# 0007. Name the project rhizo

- Status: Accepted
- Date: 2026-10-18
- Decision log: D7

## Context and Problem Statement

The project needed a name. Rust crates share one global namespace on crates.io.

What should the project be called?

## Considered Options

- rhizo, from rhizome

## Decision Outcome

Chosen option: rhizo, because it comes from rhizome and was free on crates.io on 2026-10-18. `assets/brand/BRAND.md` explains the fit: a rhizome is a root network with no fixed hierarchy, where any point can connect to any other.

### Consequences

- Good: The name matches the product idea: a graph, not a tree.
- Good: The crate name was available.
- Bad: Availability was checked on one date only.

The log lists no other candidate names.
